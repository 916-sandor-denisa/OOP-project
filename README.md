# OOP Project with Qt GUI

This project was developed during the second semester of my first year as a Computer Science student at **Babeș-Bolyai University (UBB)**. It demonstrates the application of **Object-Oriented Programming (OOP)** principles, incorporates widely used **design patterns**, and features a **Graphical User Interface (GUI)** built with the **Qt framework**.

## 🚀 Project Overview

The primary goal of this project was to design and implement a functional, interactive application that adheres to best practices in software development. It serves as a showcase of my growing expertise in:
- **Object-Oriented Programming (OOP)** principles:
  - Encapsulation
  - Inheritance
  - Polymorphism
  - Abstraction
- **Design Patterns** to create scalable, reusable, and maintainable code.

The application also includes a **Qt-based GUI** that allows users to interact with the software intuitively, offering a practical example of how to bridge functionality with user experience.

---

## 📦 Key Features

1. **Object-Oriented Programming Principles**
   - Applied OOP concepts to design robust, modular, and reusable components.
   - Created a clear separation of concerns, ensuring clean and maintainable code.

2. **Design Patterns**
   - Implemented industry-standard design patterns such as:
     - Singleton
     - Factory
     - Observer
     - Builder
   - Improved the flexibility and scalability of the codebase by leveraging these patterns.

3. **Graphical User Interface (GUI)**
   - Developed an interactive and user-friendly GUI using the **Qt framework**.
   - Included features like event handling, layout management, and intuitive navigation to enhance the user experience.
